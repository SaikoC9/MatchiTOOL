2026-11-18  Step 3 (download + install) written: AdGuardHome_MatchiTOOL.js 0.3-step3 (replaces 0.2-step2; same file name as the plugin you already load).
  What it does
    - "Install / Update": preflight must be fresh (under 5 min) and have no FAIL; asks a yes; downloads AdGuardHome_linux_arm64.tar.gz + checksums.txt from
      github.com/AdguardTeam/AdGuardHome/releases/download/<latest tag>/; REFUSES unless the SHA-256 matches checksums.txt; unpacks into /data/local/adguardhome/dl;
      runs the new program once with --version; copies old program + AdGuardHome.yaml to /data/local/adguardhome/backup/<time> (keeps the newest 3);
      swaps it in; runs --version again; puts the old one back if that fails. Never starts AdGuard Home, never writes the yaml, never touches iptables.
    - "Install from file" (offline path 3f): pick the .tar.gz (1 to 40 MB); it is sent to /data/local/matchitool/uploads, its SHA-256 is shown, an official
      SHA-256 can be pasted (install stops if different); the uploaded file is deleted after a good install.
    - If AdGuard Home is running it is stopped first (agh.sh stop when it exists); if it still runs the install stops.
