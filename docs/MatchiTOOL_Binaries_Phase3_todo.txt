KNOWN LIMITS
- Root can set the modified time back, but root can also change the app. The check is for a file damaged or replaced by another user or app.
- curl, jq and zreq are called by path from plugin scripts, which never pass through the app, so a change after start-up is only
  caught at the next start (the file is replaced then). sendat is checked before every call.
- A new binary needs its hash in BinaryHashes.kt: run python3 scripts/gen_binary_hashes.py (update_binary_hashes.py does it).
  If it is forgotten the app refuses its own copy, so validate.sh and BinaryHashesFileTest are there to stop that in CI.
