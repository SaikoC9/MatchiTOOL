# Docs style

Rules for every `.md` and `.txt` file in this repo.

- One topic per file. Do not copy text from another file; link to it.
- Start with what it is, then how to use it, then what can go wrong.
- Short sentences. One idea each. Active voice.
- Say what was tested and on which device. Do not write "should work".
- Bold only for button names and warnings. No emoji. No em dashes.
- Commands go in code blocks. Paths and file names go in backticks.
- Use the exact name MatchiTOOL (see `PROJECT_IDENTITY.md`).
- Cut filler: "simply", "just", "robust", "seamless", "best effort".
- Changelog entries: Added, Changed or Fixed, one line each.
- `.txt` files: plain text, wrapped at 80 columns, no markdown.
- Before you commit: run `scripts/validate.sh`.
