# Docs style

Rules for every `.md` and `.txt` file.

- One topic per file. Link to other files; do not copy from them.
- Order: what it is, how to use it, what can go wrong.
- Short sentences. One idea each. Active voice.
- Bold only for button names and warnings. No emoji. No em dashes.
- Commands in code blocks. Paths and file names in backticks.
- Use the exact name MatchiTOOL (see `PROJECT_IDENTITY.md`).
- Cut filler: "simply", "just", "robust", "seamless", "best effort".
- Changelog: Added, Changed or Fixed, one line each.
- `.txt` files: plain text, 80 columns, no markdown.
- Before commit: run `scripts/validate.sh`.
