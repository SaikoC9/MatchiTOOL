MatchiTOOL - Network "does nothing sometimes" fix (MTU / MSS, DHCP, router IP, Wi-Fi band, Wi-Fi settings)
Repo: MatchiTOOL-main 1.4.2. Date: 2026-11-17. Device: F50.

PROBLEM (from the user's screenshot, MTU / MSS tab)
  Wanted MTU 1500 / MSS 1449. Result: "The router is back but reports MTU 1500 and MSS 1460, not the wanted 1500 / 1449."
  Then "Mobile data is connected" and "MTU was not changed, only MSS." (wrong: MSS did not change either).

CAUSE (found in the code, NOT yet reproduced on the F50)
  The F50 answers a set command with an EMPTY reply both when it accepts it and when it ignores it (lost sign-in / no valid token).
  radio-core already handles this for band lock / cell lock (setConfirmed: read back, send again with a fresh sign-in).
  The four restart-type changes in net-tools.js did not: they called R.setRouter(call, true), accepted "empty" as sent, then waited
  ~3 minutes for a restart that never happened, and finally showed the old values as "router is back".
  This fits "works sometimes": it fails only when the router session is stale.
