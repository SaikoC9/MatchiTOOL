Full diagnose

    
Checks every function in one run: login, root shell, modem AT, router web API, USB status, firmware inspector, plugin manager and the built-in tools. It is read-only: nothing is changed on the device and no SMS is sent. The report never contains your password or token.

Update MatchiTOOL

    
Import a MatchiTOOL APK. It is checked on the device first: it must be MatchiTOOL itself and signed with the same key as the installed app. A newer version updates, the same version number with a different SHA-256 updates too, and an older version rolls back. If the SHA-256 is identical it tells you MatchiTOOL is already the latest. App settings are kept. You see the version and SHA-256 and confirm before anything is installed. Needs root access.

    
    
    
 

    
Or update online from the MatchiTOOL releases. Check for update only asks what is online and downloads nothing. When a newer build exists, Install online downloads it on the device, verifies it and installs it after you confirm. Download APK saves the file to this phone only; nothing is installed.
