Full diagnose

    
Checks every function in one run: login, root shell, modem AT, router web API, USB status, firmware inspector, plugin manager and the built-in tools. It is read-only: nothing is changed on the device and no SMS is sent. The report never contains your password or token.

    

    

    

    

  

  

    
USB controls

    
Manage Android USB debugging and USB tethering. These actions require granted root access and support varies by device and ROM.

Choose RNDIS or CDC-ECM for USB Ethernet. MatchiTOOL keeps ADB in the USB function when debugging is enabled. Restore default returns to the firmware's saved USB configuration.

    

    

  

  

    
Firmware manifest inspector

    
Inspect XML/scatter metadata and calculate SHA-256. This does not flash or modify partitions.

    
    

    

    

  

  

    
Update MatchiTOOL

    
Import a MatchiTOOL APK. It is checked on the device first: it must be MatchiTOOL itself and signed with the same key as the installed app. A newer version updates, the same version reinstalls, and an older version rolls back (app settings are kept). You see the version and SHA-256 and confirm before anything is installed. Needs root access.

    
    
 

    
Or update over the air: paste an https link to the APK (for example a GitHub release asset). Press Check for update first: it only asks what is online and downloads nothing. When a build is found the button turns into Download & verify.
