- `app/src/main/assets/bin/sendat` is an arm64 executable that the app runs as root. It is built from `tools/sendat/` (stdlib-only Go 1.22.8, `CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags "-s -w"`) by `.github/workflows/build-sendat.yml`. - `app/src/main/assets/bin/curl` is an arm64 Android executable built from upstream curl source with a statically linked OpenSSL by `.github/workflows/build-binaries.yml` (NDK clang, API 26). It needs only the system libc/libdl/libz, so it only runs on arm64 Android. curl is distributed under the curl license (MIT-style, https://curl.se/docs/copyright.html). The build recipe is the workflow above. - `jq` is built from upstream jq source by `.github/workflows/build-binaries.yml` (static, arm64; jq is MIT licensed, https://github.com/jqlang/jq). `sha256` is a 6-line shell script written for MatchiTOOL (it calls the system `sha256sum` and prints the hash of its argument (the content of a file, or the text when it is not a file), or of stdin). `zreq` is MatchiTOOL's own Go build (`zreq 1.1 (MatchiTOOL)`, static arm64, module `matchitool/zreq`, source in `tools/zreq/`). It has no built-in router password: sign-in only happens with `-pwd`, `-pwd-file` or the env `ZREQ_PWD`, and the router address must be a private or loopback IPv4. All three are copied to the app's files folder at start-up, like curl.
