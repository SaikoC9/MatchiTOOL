- `app/src/main/assets/bin/sendat` is an arm64 executable that the app runs as root. It is built from `tools/sendat/` (stdlib-only Go 1.26.10, `CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags "-s -w"`) by `.github/workflows/build-sendat.yml`. Rebuilt with the ENODATA fix, the `stty_nr0/1` ports and a `-probe` that skips ports other processes hold (`-probe -all` overrides) and `/dev/stty_nr6` as the first slot 0 guess; built by CI with `go vet` and `go test` passing; test on the F50 with `sendat -probe` and pin the port in `/data/local/matchitool/sendat.conf` if needed. SHA-256: `c7f61e688b269d924f0f5274abc599251c11341606cf99c435c64c4aa0eddbb7`. `scripts/validate.sh` fails if the file changes, so replace the hash here and there together with any new build.
- `app/src/main/assets/bin/matchi-sampler` is an arm64 executable that the app can run as root for the Live panel, when the person switches "Fast sampler" on (off by default). It is built from `tools/sampler/` (stdlib-only Go, `CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags "-s -w"`) by `.github/workflows/build-sampler.yml`, with `go vet` and `go test` passing. It only reads `/proc` and `/sys` and prints text. SHA-256 `82bc92bc78e0afb55fc914a49d4885f2abddd02e9e2ad93b51f3ac40f1594cc6`.
- `app/src/main/assets/bin/matchi-guard` is an arm64 executable that the app can run as root to watch and limit plugin processes (wall time, CPU time, memory, stuck helpers). It is built from `tools/guard/` (stdlib-only Go, `CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags "-s -w"`) by `.github/workflows/build-guard.yml`, with `go vet` and `go test` passing. It reads `/proc`, writes one JSON report and signals only tagged plugin processes. SHA-256 `cc77fea45608bc48ffdc69c30708fbbc25f7d5f2f7461ced60422a7371ae41d6`.
- `app/src/main/assets/bin/matchi-doctor` is an arm64 executable for read-only diagnostics (root, SELinux, memory, /data, CA store, TLS, router, modem, bundled-file hashes); it prints JSON and changes nothing. It is built from `tools/doctor/` (stdlib-only Go, `CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags "-s -w"`) by `.github/workflows/build-doctor.yml`, with `go vet` and `go test` passing. The app does not call it yet. SHA-256 `5badac638d193d5cd96197b7d2f7ae813e2864fc6b1b27b45dd8a836c2030471`.

It needs only the system libc/libdl/libz, so it only runs on arm64 Android. curl is distributed under the curl license (MIT-style, https://curl.se/docs/copyright.html). The build recipe is the workflow above. SHA-256: `bb49333d364737bef97b77114790be5684fd3c22d6d4274fbe56c3a83869428a`. `scripts/validate.sh` fails if the file changes, so replace the hash here and there together with any new build.
- `jq` is built from upstream jq 1.8.2 source by `.github/workflows/build-binaries.yml` (static, arm64; jq is MIT licensed, https://github.com/jqlang/jq). `sha256` is a 6-line shell script written for MatchiTOOL (it calls the system `sha256sum` and prints the hash of its argument (the content of a file, or the text when it is not a file), or of stdin). `zreq` is MatchiTOOL's own Go build (`zreq 1.1 (MatchiTOOL)`, static arm64, module `matchitool/zreq`, source in `tools/zreq/`). It has no built-in router password: sign-in only happens with `-pwd`, `-pwd-file` or the env `ZREQ_PWD`, and the router address must be a private or loopback IPv4. All three are copied to the app's files folder at start-up, like curl.
