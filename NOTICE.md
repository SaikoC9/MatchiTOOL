- No `nfqws` executable is bundled.
- `app/src/main/assets/bin/sendat` is a prebuilt, UPX-packed arm64 executable that the app runs as root. Its source and build recipe are not recorded in this repository. SHA-256: `f0da6be08ed2cdb46f517baa8d964327d2550b68017468d2dbbe4aa8224e41a9`. `scripts/validate.sh` fails if the file changes, so replace the hash here and there together with any new build.
- `app/src/main/assets/bin/curl` is a prebuilt arm64 Android executable (curl 8.0.1-DEV) taken unchanged from the UFI-TOOLS V4.0.0 APK (`assets/shell/curl`). It links the device's own libssl/libcrypto/libz, so it only runs on arm64 Android. curl is distributed under the curl license (MIT-style, https://curl.se/docs/copyright.html). Source and build recipe are not recorded in this repository. SHA-256: `5627a31714a8c621d7ca56539af5b95f439bdbbc125b6aab301897fed3c4632a`. `scripts/validate.sh` fails if the file changes, so replace the hash here and there together with any new build.
- `app/src/main/assets/bin/jq`, `sha256` and `zreq` are prebuilt arm64 executables taken unchanged from the UFI-TOOLS 4.1.5 APK (`assets/shell/`; `sha256` was replaced in 1.4.1, see below), added in 1.4.0 so plugins that call `/data/data/com.minikano.f50_sms/files/NAME` find them (the path is rewritten to this app's files folder). They are copied to the app's files folder at start-up, like curl. `jq` is a statically linked ELF (jq is MIT licensed, https://github.com/jqlang/jq). `sha256` is NOT the UFI-TOOLS binary any more: since 1.4.1 it is a 6-line shell script written for MatchiTOOL (it calls the system `sha256sum` and prints the hash of its argument, or of stdin); the old packed binary had no recorded source. `zreq` is a Go program; UFI-TOOLS ships its source as `zreq.go` (MIT, see `LICENSE-UFI-TOOLS`). Note that `zreq`'s built-in default router password is UFI-TOOLS' own; MatchiTOOL never passes it. SHA-256: jq `91bb0b08fd8053c04be41846f83be24bfa06d5c1eac2c0c925298638c642ea52`, sha256 `c9a941a15741e1f2fa1e183da05a837b08297d89453165d3a7882f481994aa45`, zreq `b7b0b01e55dcd3cf758648cba63d67f83fa72cbadeb4687eda514741fb76600d`. `scripts/validate.sh` fails if any of them changes, so replace the hash here and there together with any new build.
- `ufi_req`, `socat`, `ttyd`, `adb`, `iperf3` and `imei_reader` from UFI-TOOLS are NOT bundled: no plugin in the Phase 0 corpus needs them (the corpus is still empty, so this is a guess to revisit when real plugins are collected).
